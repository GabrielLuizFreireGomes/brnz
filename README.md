# brnz

Site da brnz.

## Aplicativo BRNZ

O aplicativo está em [`app/`](app/README.md), separado do site Astro. Execute `cd app` e `npm run dev` para abrir em **http://localhost:4322**.

Documentação: [produto](app/docs/PRODUTO.md), [estrutura técnica](app/docs/ARQUITETURA.md), [identidade visual e referências no site](app/docs/IDENTIDADE-VISUAL.md) e [validação](app/docs/VALIDACAO.md). A etapa atual usa dados mockados locais, com perfis de cliente, equipe e administrador.
